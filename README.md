# Quản lý đăng ký câu lạc bộ

Ứng dụng desktop được xây dựng bằng C# WinForms nhằm hỗ trợ quản lý thông tin đăng ký tham gia câu lạc bộ. Đây là sản phẩm bài tập lớn môn Lập trình trực quan C#.

## 📌 Giới thiệu

Phần mềm cung cấp giao diện trực quan giúp người dùng thực hiện các thao tác quản lý đăng ký thành viên câu lạc bộ một cách thuận tiện.

## 🚀 Hướng dẫn cài đặt và chạy

1. Clone repository về máy:

   ```bash
   git clone <URL_REPOSITORY>
   ```

2. Mở file `.sln` bằng Visual Studio.

3. Khôi phục các package cần thiết nếu có.

4. Cấu hình kết nối cơ sở dữ liệu nếu cần.

5. Build solution và chạy ứng dụng bằng `F5`.
